### 1. 三层验收体系（本轮最重要的架构产出）

| 层 | 工具 | 回答什么 | benford 状态 |

**三层互补**：注意力管时间轴上的能量分布，静态焦点管空间上的显著性归属，动态焦点管焦点运动的叙事合理性。

#### 静态焦点判据 fq
- `focusShare`：主体 focus 框内显著性占总质量比（有没有焦点）
- `hotspotInside`：全局最强 10% 窗口中心在不在 focus 框内（焦点对不对）
- `stability`：相邻 hotspot 位移中位数甜区 0.06（焦点稳不稳）
- `fq = 0.5*share + 0.3*insideRate + 0.2*stabilityScore`
- 分角色阈值：release fq≥0.55/share≥0.45/inside≥0.75；hold/pressure fq≥0.30-0.35；residue fq≥0.35

#### 动态焦点判据 dfs
- `trajectoryCoherence`：三步方向余弦（hold/pressure 允许扫描只罚大幅往返，release/residue 严格定向）
- `transitionQuality`：块边界跳变比（跨场景 cut 点豁免，hold→release 看 1.2s 窗口容 spring 延迟）
- `narrativeAnchoring`：release 用分布集中度 1−H/log3（focus 框是逻辑坐标不随 zoom 变，不能和固定屏幕位置比）；其他角色用余弦相似度
- `motionRhythm`：各角色速度中位数 vs 期望带（pressure 0-0.03 / hold 0.02-0.10 / release 0.03-0.15 / residue 0.01-0.06）
- `dfs = 0.3*coh + 0.25*trans + 0.25*anch + 0.2*rhythm`

## 四、环境坑（本轮新增）

- **setXform anchor 是缩放不动点**，不是「把这点移到屏幕中心」。居中某对象须用默认 anchor + `x=scale*(W/2-objCx), y=scale*(H/2-objCy)` 位移。直接 anchor=[objCx,objCy] 会把对象推出画。
- **rhythmDrive hold 包络 slam 恒为 0**（只有 release 有 slam）。hold 块首动作要自算 `smoothstep(0,~0.1,rd.u)`。
- **focus 框是逻辑坐标不随 zoom 变**。动态焦点锚定判据 release 期用分布集中度而非固定屏幕位置期望。
- **字幕保留带 [40,104]**：zoom anchor 在画面中心时顶部文字会被推入字幕带。表头/公式用屏幕坐标 overlay（撤变换后画）或下移避开。
- **paper 亮底上 ink 深色探针反而降 diversity**（与主体同色被算法合并），signal 红独立色更好。但用户不许用探针刷分。
- **B 站搜索 API 裸请求 412**：需先 GET 首页拿 buvid cookie 再带 Referer 访问。`pubtime_begin_s/end_s` 可做发布时间过滤。
- **个别视频无 480p avc 流**：用 30011（360p hvc1）+30280 替代。
- **ffmpeg drawtext fontfile 冒号转义在 Windows 极易碎**：改用 textfile + 默认字体；% 是展开符要避开。

## 六、用户红线（必须遵守）

1. **不许用高亮轮换/外部探针/装饰流带刷复杂度分**。复杂度必须来自真实内容组合。
2. **单主体科普复杂度 44-46 是诚实天花板**，接受它而不是硬提。
3. **焦点可以动但要有叙事意图**，不是钉死不动也不是乱跳。
4. **数学符号要真排版**（下标/分式/斜体），不用 Unicode 凑合。
5. **表头不能被字幕挡**，要有视觉焦点不只是「不挡就行」。
