## 三、关键结论（修正第二批的「浅蹲」建议）

1. **两种形态都成立，但参数完全相反——不能混用一条目标曲线**：
   - **aigen 型**：高位保持（均值0.65、hi65≈59%、几乎无深谷），靠满画面密集小变化。
   - **bit 型**：**深谷叙事**（均值0.48、59%时间在0.5以下、落差0.45、波幅0.073），
     深色底+单主体代码动画天然显著性低，但**峰谷摆动大**、每5s一个节奏循环。
     554万播放的《银牌的眼泪》hi65只有1%、最长低段44s——**深谷不是缺陷，是这个形态的常态**。
2. **我们的引擎产物（paper暖纸底/深色底+单主体矢量动画）与 bit 型同构**，
   第二批「曲线上移0.15、浅蹲0.55」的建议**只适用 aigen 型，对我们要撤回**。
   正确对标是 bit 组加权值：**均值≈0.48、前3s峰≈0.57、落差≈0.45、波幅≈0.07、周期≈5s**。
3. **bit 型的谷段时长分布**（8支121段实测）：1-2s×32、2-4s×28、**4-8s×39**、8-16s×14、16s+×8。
   → pressure 下蹲 **4-8s 是主流**（占1/3），ATTENTION-CURVE-SPEC 的「下蹲持续几秒」方向是对的，
   0.32 的目标值也与 bit 型实测谷位（0.22-0.45）相容。**原规范对 bit 型基本成立，不必改骨架**。
4. **钩子**：bit 型前3s峰加权 0.569（0.41-0.65 带宽），比 aigen 的 0.683 低一档。
   我们之前定的「前3s峰≥0.69」是按 aigen 定的激进值；对 bit 型 **≥0.60 即达标杆上沿**（以牙还牙0.65/起风0.63/酿酒0.63）。
5. **用户指定4支定位**：剃刀(user)均值0.49/落差0.44、熵增0.45/0.47、刷分0.51/0.47——三支都是标准 bit 型；
   江离《涌现》均值0.36/95%时间<0.5 是**极暗底长留白型**（231万播放），说明 bit 型内部还有更低的亚型，
   但它钩子只有0.43，是四支里最弱的开场。
6. **不变量（跨组一致）**：锯齿周期 4.4-5.1s（规范写5-8s偏慢，块内应有1-2个小波纹）；
   峰后必回落（R8）；结尾不归零。这三条是真正的通用规则。

## 四、落地：双形态目标曲线

`expectedAttention` 应按任务形态分档（task.config 加 `attentionProfile: 'bit' | 'aigen'`，缺省 bit）：

| 角色 | bit 档（我们主力） | aigen 档 |
|---|---|---|
| 前3s钩子 | 0.45→0.60（1s峰）→0.55 | 0.40→0.70→0.65 |
| pressure | 0.52→0.30（4-8s深蹲） | 0.58→0.52（1-2s浅蹲） |
| hold | 0.38±0.05 | 0.55±0.04 |
| release | 0.35→0.70 | 0.55→0.72 |
| residue | 0.55→0.40 | 0.65→0.58 |

验收线（bit 档）：前3s峰≥0.57；落差≥0.40；波幅≥0.06；最长<0.55段≤10s（允许深蹲但不允许躺平）；
锯齿周期 4-6s。**不再要求 ≥0.65占比**（bit 型标杆只有1.6%）。

benford 当前实测（均值~0.55、落差0.25、hook 0.57）对照 bit 基准：**钩子已达标**，
差距在**落差与波幅**——release 峰只到 0.63（标杆 0.70）、谷不够深（hold 0.61 vs 标杆 0.38）。
方案2接线方向正确，下一步把 hold 段显著性压下去（背景门控+主体静置）比把峰推高更重要。
