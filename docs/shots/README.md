## 选型纪律

- **先问这一段要干什么**，再按分类找卡；不要从「我想画个柱状图」倒推。
- 一段里只让观众看一件事（docs/LAYOUT.md）；两张卡叠着用，主体就没了。
- 相邻两段别用同一张卡 —— 同质化从这里开始。
- 卡片只是起点：参数调到「除默认值外每项都动过」，通常才不像模板。
- 卡里没写的效果就是没有：要新视觉回 §3 手写场景，别硬改参数。
