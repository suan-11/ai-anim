## 2. 参数化转场（1-13）：8 种模式，一个字段

```js
{ type: 'chart', title: '…', dur: 4, overlap: 1.2, transition: 'wipe' }
```

| 名字 | 画面 | 实现 |
|---|---|---|
| `push`（默认） | 旧帧沿摄影机方向加速甩走 | `TRANSITION_FRAG.push` —— **与 2026-10-30 之前逐字符相同** |
| `mix` | 交叉溶解（旧默认） | `compositor.mixTo`（不走 Pass） |
| `none` | 硬切 | 什么都不做 |
| `wipe` | 软边横扫 + 前沿暖光 | 新 |
| `iris` | 正圆从中心张开（按 `RES_LOGICAL` 长宽比校正） | 新 |
| `glitch` | 横向切片错位 + RGB 分离 + 极短闪白 | 新 |
| `pixel` | 格子由密到疏、逐格消失 | 新 |
| `dissolve` | 多尺度 `fbm` 阈值溶解，边缘发亮 | 新 |

**位置**：

| 件 | 位置 |
|---|---|
| 六支 shader | `src/core/transition-frag.js`（共用 `under`/`k`/`dir`/`push`/`blur`/`fadeAt`） |
| 模式表 + 校验 | `src/core/trans.js` 的 `TRANSITION_MODES` / `resolveTransitionMode` / `transitionFadeAt` / `isPassTransition` |
| 引擎接线 | `src/core/engine.js` 的 `composite()`（按 `item.transition` 选模式）+ `_pushTransition(…, mode)`（**按模式缓存 Pass**） |
| kit 转发 | `src/kit/world.js` / `src/kit/index.js` |
| 夹具 | `tasks/_trans-lab`（8 模式 × A→B，`overlap: 1.2`，含 `push`/`mix`/`none` 三个对照组） |
| 回归 | `tools/test-transition-modes.mjs`（24 项） |

### 2.1 四条纪律

1. **不写 = `push` = 逐像素与从前一致**。`push` 的 shader 源码被两个单测逐字符钉着。
2. **写错当场抛**并列出可用值。静默回落成甩镜 = 画面照样出、`check` 照样绿，只把「我要的擦除怎么没出现」留给人。
3. **掩码型转场的 `alpha` 就是时间轴** —— 不要再叠一层全局淡出（两个 fade 相乘 ⇒ 中段发灰）。
4. **`fragColor` 的 alpha = 「旧帧还剩多少」** —— 改语义等于改转场语义。

## 3. 纸艺层叠（1-66）：三个只有出图才看得见的比例

`src/kit/paper.js`：`tornEdge` / `paperShape` / `paperFace` / `paperStack` / `paperGrain` / `shadowColor` / `coreColorOf` / `translateShape`。
覆盖素材包 **20 条**，是 `REFERENCE-style-pack-capability.md` §3 缺口表里复用度最高的一项。

**一张纸要像纸只有三件事**：硬投影 / 分形撕边 + 白芯 / 纸色纤维。

### 3.1 三个比例（第一版全错，现在都是硬断言）

| 数 | 正确值 | 第一版错在哪 |
|---|---|---|
| 撕边幅度 | **边长 × 1.5–3%**（2040px ⇒ 40px） | 12px ⇒ 缩略图里是**一条直线** |
| 撕边采样密度 | **约 8px 一个点**（按边长自动定） | 默认 40 点 ⇒ 每 51px 才一个点，毛刺被 `fillPoly` 的折线**抹平** |
| 白芯提亮 | **7%** | 35% ⇒ 一条雪白高光带，像**贴纸白边** |

> **第 ② 条是这轮最值钱的发现**：几何本身完全正确，是**采样把细节吃掉了**，
> 而 `check` 的三点采样永远绕得过去 —— 只有把图放大才看得出来。
> 推广：任何「按参数生成点列再填充」的东西（撕边、等高线、粒子轨迹）都要问一句
> **采样密度够不够表达我要的最高频**，而不是「函数写对了没有」。

### 3.2 三件容易写错的事

1. **撕边只吃 `seed` 不吃 `t`** —— 纸不会每帧重新撕一遍（也让子帧累加不会糊）。
2. **层栈由远到近画** —— 线段批没有 z-test。
3. **投影方向全片一致**，且必须**不透明**（半透明黑会在扫描行之间出条纹）。
