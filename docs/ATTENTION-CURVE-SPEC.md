# 认知注意力曲线设计规范

> 来源：用户提示词（2026-11-23）。性质：节奏双轨制的**目标曲线设计依据**。
> 关联：`docs/BRIEF-rhythm-dual-track.md` §9 / `docs/RHYTHM-EVALUATION.md` §3 / `scripts/lib/attention-rhythm.mjs` expectedAttention / `src/core/rhythm.js` R6–R8。

## 0. 两种曲线分开看

| 曲线 | 看什么 | 形态 |
|---|---|---|
| **行为留存曲线**（平台数据/CRM） | 有没有走 | 天然单调下降；好的留存=降得慢+平台期+偶尔小回升（反转/新信息/情绪峰/视觉突变）。找**陡降点**=注意力断裂。 |
| **认知注意力曲线**（注视同步/主观专注） | 在不在看 | 波动有峰谷，不天然下降。**这才是节奏表要设计的目标**。 |

两条趋势一致但形态不同：留存陡降处，认知通常也在谷底。本引擎的注意力曲线（`rhythm --attention`）是**认知曲线**的画面显著性代理估计。

## 1. 硬规则（曲线骨架）

1. **起点不能低**：前 3 秒必须陡升或高开，否则后面没机会。
2. **中段是锯齿**：短视频每 5–8 秒一个小起伏，有升有降，不是高位直线。
3. **高潮前主动压低**：大释放前曲线明显「下蹲」蓄力（阻力系数最高）。
4. **峰值之后回落**：释放完不回落，下一次张力起不来。
5. **结尾不能断崖**：可缓降、可小回扣，不能突然崩到零。

## 2. 分阶段形态（短视频 15–60s）

| 阶段 | 时刻 | 曲线形态 |
|---|---|---|
| 陡升段 | 0–3s | 快速拉到中高位（不是最高），让观众知道值得看。平的前3秒后面难救。 |
| 建立段 | 3–15s | 维持中高位+小幅波动，轻微下降再拉回（差点想走被拉回）。 |
| 锯齿波动段 | 中段 | 小高潮—回落—小高潮—回落；回落低点停**中位**不归零；峰值逐渐抬高为大高潮铺垫。 |
| 主动下蹲段 | 高潮前 | 降到中低位持续几秒（压弹簧），阻力最高。大多数片子缺失这段。 |
| 峰值段 | 高潮 | 冲全片最高点。有力是因为前面有下蹲。 |
| 余韵段 | 结尾 | 峰值后快回中位再缓降，不归零；可小回扣（回扣开头问题）轻微回升再收束。 |

## 3. 四段角色 → 曲线映射（核心纠正）

| 角色 | 曲线动作 | 目标值（expectedAttention） |
|---|---|---|
| **pressure** | **主动下蹲**（不是往上冲！压弹簧） | 0.58 → 0.32（中位降中低位） |
| **hold** | 停低/中位制造期待 | 0.40 ± 0.04 微起伏 |
| **release** | 冲峰值 | 0.42 → 0.88（蓄势末低点猛升） |
| **residue** | 回落中位缓降不归零 | 0.62 → 0.42（结尾块 0.52→0.42+小回扣） |

> ⚠ 旧版 pressure 是 0.34→0.61 上升——**错了**。pressure 是下蹲蓄力，不是冲高。

## 4. 循环硬规则（R6–R8，机器校验）

- **R6**：不允许连续两个 release 相邻。
- **R7**：每个 release 之前必须有至少一个 pressure 或 hold（蓄势）。
- **R8**：release 之后不能直接接 pressure（须先经 residue 余韵，再启下一轮）。

四段循环骨架：`pressure → hold → release → residue → pressure → …`

## 5. 内容类型差异

| 类型 | 曲线特征 |
|---|---|
| 短视频（15–60s） | 前3秒陡升，中段每5–8秒锯齿，结尾快速收束不留长余韵 |
| 叙事型长视频 | 波浪缓降，每2–3分钟小高潮，大高潮在70%–80%位置，结尾回扣 |
| 信息型/教程 | 平台期长，靠新信息点制造小台阶，阶梯状下降 |
| 情绪型/氛围型 | 整体较低但平稳，少数峰值撑住，峰值间允许长留白 |

## 6. 验收

- 前3秒陡升（钩子 peak≥0.55 且峰谷差≥0.12）。
- 每个 release 前有下蹲（pressure/hold），峰比蓄势末高≥0.08，比随后 residue 末高≥0.08。
- 结尾不归零（residue 缓降+可选小回扣）。
- R6–R8 循环骨架合规。
