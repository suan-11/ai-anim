### 2.3 放包 & 跑

```powershell
# 把 cross-gpu-bundle 整个目录放到：
#   out/_remotion-migration/acceptance/cross-gpu-bundle/
# 或放在任意位置，用 --bundle 指过去：
node tools/cross-gpu-repro.mjs --bundle D:\path\to\cross-gpu-bundle
```

默认跑全套（28 张固定帧 + 3 支草稿），预计十几分钟（`three-lab-draft` 一支就 876 帧）。常用开关：

- `--skip-video`：只跑固定帧，视频项记 `SKIPPED`；时间紧时先跑这个也能定位驱动差异。
- `--out-dir <目录>`：指定独立输出目录（不能指向 `baseline/` 或包根目录）。
- `--verify-only --out-dir <已有 run 目录>`：不重渲，只对已有产物重算比对。

### 2.4 回传什么

跑完写 `runs/<run-id>/`，回传这两个文件即可：

```
runs/<run-id>/repro-report.json
runs/<run-id>/repro-report.md
```

环境信息（hostname / OS / Node / npm / Remotion / Chrome / ffmpeg / GPU / WebGL 字符串）**已自动采集**在报告的 `machineB` 字段里，不用另填表。

### 2.5 判据（报告里看哪几个数）

| 判据 | 通过线 | 说明 |
|---|---|---|
| 同会话乱序同帧确定性 | `determinismFailures = 0` | `paperfold` 的 `204,48`、`three-lab` 的 `339,120` 重复渲染必须 **SHA-256 逐字节相同** |
| 跨驱动固定帧 | `divergedFrames = 0` | 允许 1–2 个色阶差异：RGBA 平均差 `mean ≤ 3.0` 且单通道 `>8` 的像素 `≤ 2.0%` |
| 草稿 MP4 | `failedVideos = 0` | `ffprobe` 宽/高/fps/帧数/时长/音轨数/编码器一致；抽帧 `mean ≤ 6.0`、`>16` 占比 `≤ 5.0%` |
| 总结 | `summary.passed = true` | 上面三条都满足 |

**跨机 SHA-256 不同不直接判失败**（不同 ANGLE/驱动的栅格化四舍五入），真正判据是"同机重复一致 + 跨机在容差内"。

**为什么阻塞**：`narration.mjs` 的 `VOICE = 'cotton-ja'` 是 GPT-SoVITS 克隆音色。`ja-vo.mp3` / `ja-mix.mp3` 是派生产物，但**只有那套音色能重建**；本机没有 `D:\gptsov\`，也没有参考音频。

**路线 A：补上克隆音色（推荐，不改交付物）**

```powershell
# 0) 起 GPT-SoVITS API（api_v2.py，默认 9880），并给参考音频
$env:ANIM_GSV_API       = 'http://127.0.0.1:9880'
$env:ANIM_GSV_REF       = 'C:/path/to/ref/voice.wav'   # 3–10s，干净、无音乐
$env:ANIM_GSV_REF_TEXT  = '参考音频里说的那句原文'
$env:ANIM_GSV_REF_LANG  = 'ja'
$env:ANIM_GSV_TEXT_LANG = 'ja'

# 1) 重建旁白（钉住既有 47.244s 时间线，别让它漂）
node scripts/anim.mjs say nekohome-intro-ja --table ja --rate +8% `
  --tts "python tools/tts-gptsovits.py" --pin-timing --pin-table ja

# 2) 中文字幕表（时间轴=日语，文本=narration.mjs 的 zh 字段）
node scripts/make-ja-zhsub.mjs

# 3) 混音
node scripts/anim.mjs mix nekohome-intro-ja --table ja --target streaming
```

跑完先看 `git diff tasks/nekohome-intro-ja/audio/ja.timing.json`：`total` 应仍是 `47.244`、各段 `slot` 不变。若某句变长放不进原 slot，`say` 会警告并重解那一段 —— **段长一变整片要重出**，这时先停下来判断。

真实音画验收：

```powershell
node scripts/anim.mjs video nekohome-intro-ja --renderer remotion --draft --samples 1 --segments 10
node scripts/anim.mjs qa nekohome-intro-ja --renderer remotion `
  --file out/nekohome-intro-ja/nekohome-intro-ja.remotion.draft.mp4 `
  --expect-size 960x540 --expect-fps 60 --expect-duration 47.25 --audio required --strict
```

判据：`0 错 / 0 警`；再按矩阵 §3.4 的口径抽首/中/尾三帧看字幕、用 `silencedetect` 核句首偏差。

## 5. 环境坑（都实测过）

| 症状 | 原因 / 解法 |
|---|---|
| `pre-encode.mp4: Permission denied` | 系统 `TEMP` 不可写。把 `TEMP`/`TMP` 指到 `out/_remotion-migration/acceptance/tmp` |
| 报 `没有 edge_tts`，但 `python -c "import edge_tts"` 能过 | `py tools/tts-edge.py` 会按脚本 shebang 走到别的解释器。用 `ANIM_PYTHON` 显式指定 |
| `WSServerHandshakeError: 403` | `edge-tts` 版本太旧（7.2.8）。换 7.3.1+ 的解释器 |
| 提交卡住 / `SIGTERM` | 预提交钩子跑 `precommit-report.mjs` 约 100s，终端超时给足 |
| 沙箱里 `git push` 返回 255 | 用 Git 自带 ssh：`git -c core.sshCommand='"C:/Program Files/Git/usr/bin/ssh.exe"' push origin HEAD` |
