# 节奏双轨数据评估标准

这份标准用于填写 `rhythm.json`、审看渲染结果和记录改版前后的证据。时间统一用原片秒数，块区间为 `[t_start, t_end)`。节奏块可以跨镜，也可以在镜头内部切换。采用节奏事件轨的任务以事件时刻编排动作和切点，BPM 提供参考坐标。

## 1. 先确定评审对象

1. 固定任务、变体、实际片长和待评 MP4。改版对比使用同一画幅、帧率、采样步长和主体框。已有 MP4 先核对时长和版本，片段预览只能代表对应时段。
2. 盲看片段一次，逐块写下主锚点、应发生的变化和关键时刻。再打开节奏表与曲线复核。每块至少看入、中、出三处，`release` 额外看峰值和它的前一帧。
3. 对每个问题记录 `原片时刻 / 字段或指标 / 预期 / 实测或画面证据 / 结论`。**通过**表示证据达标，**待修**表示有明确偏差，**未评**表示缺证据，**不适用**表示任务确实没有该轨或该窗口。

## 2. 节奏表逐项评分

| 字段 | 如何填写和复核 | 当前机器检查 |
|---|---|---|
| `t_start` / `t_end` | 从 `0s` 起连续覆盖整片，每块 `3–8s`。用主锚点的状态或运动变化定边界，并记下块内实际峰值。设计与边界同时触发的切点或动作，取成片时差 `≤1` 帧。 | `lint-rhythm` 查格式、块长及相邻边界。渲染装载后还核对整片覆盖时长，`check` 可见。 |
| `intensity` | 按下表给 `1–5`。同片采用同一尺度，观察主锚点的位移、速度、形变或光的冲击。写 `5` 的块应有可指认的主要峰值。 | R1 禁止连续三块同分。分数与画面是否一致须复看。 |
| `info_density` | 按下表给 `1–5`。用块内最密的持续约 `1s` 判断观众必须同时辨识的独立信息。单纯一闪而过的彩蛋不作为常态密度。 | R2 要求每个 `≥4` 的块紧接一块更低分的块，含尾块情形。 |
| `resistance` | 给 `0–1`。`0–<0.25` 为迅速展开，`0.25–<0.50` 为轻阻，`0.50–<0.75` 为明显受限，`0.75–1` 为强持压。看主动作何时开始、何时走到目标的一半，以及收紧和放开的方向。 | R3 要求 `release` 前一块阻力大于释放块。还有再前一块时，它须低于前一块。 |
| `attention_target` | 写 `single_anchor`，评审记录里注明锚点名称，场景或镜头声明 `focus`。主对象变化可以跨块接力。单块内出现第二对象时须能看出明确的交接顺序。 | R4 查声明值。布局和像素显著性分别提供呈现证据。 |
| `motion_grammar` | 写可核对的动词名称，如 `radial_gather`。评审能指出主体、方向和终态，例如波前向核心收拢。 | 可选。提供时须是非空字符串。 |
| `sound_density` | 给 `0–1`。依据混音里同时可辨认的功能层，并另记有叙事作用的起音、停声和音色变化。见 §4。 | 可选。提供时只查取值范围。 |
| `beat_role` | 从 `pressure`、`hold`、`release`、`residue` 中选一个，观察相邻块之间的作用。 | R5 要求全片至少出现三类。逐块角色语义与循环是否成立须复看。 |

### 强度和信息密度档位

| 分值 | `intensity` 画面动作 | `info_density` 独立信息单元 |
|---|---|---|
| 1 | 余韵或微动。主状态基本建立，变化轻且局部。 | `0–1` 个。一个锚点或留白。 |
| 2 | 动作清楚可见。变化仍主要留在原锚点附近。 | `2` 个。主体和一个需要独立理解的标注或关系。 |
| 3 | 主体有连续、明确的推进、收紧或形变。 | `3` 个。可在一个阅读顺序内处理。 |
| 4 | 一次明显加速、开合或状态对比，占据主要画面。 | `4–5` 个。需要分批揭示或紧接换气。 |
| 5 | 全片主峰或明确的并列主峰。有一个压过其他动作的可定位变化。 | `≥6` 个。需要指出观众先看什么，以及紧随其后的卸载块。 |

同一个字句、同一组频谱格或共同组成一条曲线的重复图元按一个意义单位计。只有观众需要分辨各自的意义时才拆开。图元数可作为渲染负载或视觉密度的证据。若它与语义单元给出的档位不同，分别记录两个数。

验证阻力映射时固定其他字段，比较同一镜头的低、高 `resistance` 取样。用同一路径上的半程时间或相同时刻的位移举证。阻力高的一版应更晚达到半程或在受约束方向位移更小。没有可跟踪的主动作时标记未评。

### 事件角色的评审证据

| 角色 | 通过所需的画面或声音证据 | 常见偏差 |
|---|---|---|
| `pressure` | 主体、信息或声音收向下一事件，能指出约束怎样增强。 | 画面一直匀速漂移，下一块与前面无关。 |
| `hold` | 前一块已经形成张力。主状态保留，有可见微动、局部持续或有意的停顿。 | 关键变化已经完成，剩余时间没有维持作用。 |
| `release` | 能指出所释放的约束、主要变化及峰值时刻。 | 只有放大、闪白或卡拍，未发生预先铺垫的变化。 |
| `residue` | 同一主体或后果仍可辨认，能量、信息密度或声音层次相对释放回落。 | 大标题、强音或新主体立刻占满画面，截断上一事件。 |

## 3. 注意力判读

`anim rhythm <任务> --attention` 输出 `0–100` 分及独立的开头、波峰回落检查。默认每 `0.25s` 采样，另采镜头、节奏块和 `3s` 边界。光照、移动轮廓与字幕都可能贡献显著性，先用热图确认来源。

### 加权方差评分

1. 每帧代理值 `A = 0.75 × strength/(strength+8) + 0.25 × concentration`。`strength` 是像素局部对比和帧间变化的平均强度，`concentration` 是显著性集中度。主体框面积与落框读数保留用于定位问题。
2. 目标值 `T` 在前 `3s` 用 `0.44 → 0.82 → 0.58` 的开场轮廓，峰在 `1s`。`3s` 后按角色定义。蓄势沿块进度从 `0.34` 升至 `0.61`，持压取 `0.60`，释放取 `0.80`，余韵从 `0.56` 回落到 `0.30`。
3. 设残差 `e = A − T`。每个样本的权重是到下个样本的时长，前 `3s` 部分乘 `2`。令 `μw = Σ(w × e) / Σw`，加权方差 `Vw = Σ[w × (e − μw)²] / Σw`。得分为 `round(100 × max(0, 1 − sqrt(Vw)/0.25))`。
4. 水平偏差另看 `|μw| ≤ 0.12`。始终偏亮、偏暗或曲线过于平坦时，结合钩子与峰谷结论判断。自首帧取样点过密的区间仍按实际停留时长加权。有效权重不足目标权重 `80%`、缺完整节奏表或选段报告时，整片分数记未评。

上述权重和阈值是本项目的首版校准值。比较不同版本时固定常数和采样设置。

### 开头、后续起伏与收尾

| 位置 | 量化检查 | 人工评审证据 |
|---|---|---|
| 前 `3s` | 用六个 `0.5s` 窗。至少四个窗有效，最高窗均值 `≥0.55`，最高与最低相差 `≥0.12`，报告峰值候选时刻。 | 关闭声音先看首帧和第一秒。能指认抢眼的主体与它正在发生的变化。前三秒留下一个待揭示的结果或兑现第一层结果，后文继续兑现期待。标题、音效和亮度单独制造出的波峰进入复看。 |
| 后续每次 `release` | 峰取该释放块内最高 `0.5s` 窗均值。峰比前一 `pressure` 或 `hold` 末一秒均值高 `≥0.08`，也比随后的 `residue` 末一秒均值高 `≥0.08`。报告每次升幅、回落量以及缺失段。 | 峰产生一个新结果，回落给观众消化或为下一事件留空间。同一动作有起有收，热点转移可说清交接对象。两个峰之间若 `10s` 内说不出新增信息、决策或结果，记为复看片段。 |
| 片尾 | 查看最后一次峰谷的时间码，同时查看 C5 尾窗与低活动窗口。 | 兑现开头提出的问题，停在结果可读的地方。列出兑现时刻和余韵结束时刻，检查尾部每个重复元素有何用处。 |

全片至少有一轮可测的后续起伏。开头候选、后续每轮和水平偏差均达线时，报告显示波形通过。主观钩子及内容兑现保留独立结论。

| 读数 | 口径 | 评审动作 |
|---|---|---|
| 主体内显著性占比 | 框内显著性总量 ÷ 全帧总量。与此同时记录主体框面积占比和有效样本数。 | 在同镜头、同框下比较。占比低于框面积占比，或比对应基线下降 `≥10` 个百分点时先抽看热图。高占比遇到大框仍须核对是否只有一个锚点。 |
| 热点落框 | 热点落在框内的帧数 ÷ 同时具备主体框和显著性信号的帧数。 | 连续 `≥0.5s` 的框外热点先看主体是否有意越界。若持续吸引注意的是无关标签、背景或另一个主体，记待修。单个边界采样按切镜或交接复看。 |
| 集中度和热点轨迹 | 集中度是约 `10%` 画面面积内最强区域占全帧的比重。轨迹展示该区域的加权中心。 | 高集中度时核对热点是谁。低集中度时查看是否同一主体展开或是否出现多个分离热点。用节奏块最低点、移动方向和对应画面定位问题。 |

上面的降幅和持续时间是 v0.2 的抽帧起点。判定待修需要对应画面证据。无合法主体框、交叠或无有效像素信号的帧记未评，并报告分母。不同主体框或不同光效的片子需重新校准。观众实际注视和语义理解由独立观测验证。

## 4. 声音和拍网格

- **声音密度**按 `0.5s` 划窗，在混音中逐窗标注实际可辨认的音乐、话语和动作音效。有辨识作用的一层计 `1`，每类每窗最多计一次。以 `Σ(可辨认层数 × 窗实际时长) / (3 × 块时长)` 得到复核值。持续单层音乐约为 `0.33`，纯静音为 `0`。同一音乐轨里的鼓、贝斯和高帽共享一个功能层。无法听清层次时记未评。
- **声音事件**单列 `原片时间 / 事件角色 / 声音变化`。例如释放时的冲击、余韵时落下的配乐或主动留空。功能层少时也可能有重要音效，复核值与编排值不同先听对应时段。混音响度、真峰和削顶另外走响度检查或 `qa`。
- **拍网格**有有效拍表时，记录 BPM、切点到最近拍的有符号误差和需要时的小节误差。已声明双轨的片子，无论误差是否在默认 `±30ms` 内，都按事件轨的动作或切点意图评审。纯静音任务的拍网格记不适用。
- 每个关键事件用 `铺垫起点 / 主变化 / 完成点` 三个时刻复核。强度对照主变化处的位移速度、形变量或变化面积。阻力对照同一路径到半程的时间。信息密度在主变化前和后各记录一个代表性 `1s` 窗。声音标点用混音里可听见的起音时刻对照同一事件。这样可以定位哪个字段偏离了预期。

## 5. 全片读数和现有判据

| 指标 | 当前阈值 | 怎么复核 |
|---|---|---|
| C4 镜头时长 | 节奏双轨报告中的镜头长度 CoV `≥0.25`。每个完整 `30s` 窗应有一段时长 `≥2.5s` 的镜头在窗内开始。 | `check`、`review` 或 `lint-anti-ppt`。镜头长度与节奏块长度分别计算。短于 `30s` 的片子无完整呼吸窗口。 |
| C5 过程钩子 | 每 `10s` 窗按镜头起点计，包括尾部不足 `10s` 的窗口。段长 `≤1.2s`、声明 `light` / `material` 或强转场的镜头计入。默认允许漏 `≤25%`，严格档允许漏 `0`。 | `check` 或 `lint-anti-ppt`。命中后复看切点。片内有强事件而声明或起点未入窗时，记录具体证据。 |
| 成片事件密度 | `4fps`、`480×270` 灰度帧间差。最长静止 `≤3.5s`。运动量低于全片完整 `2s` 窗均值一半的窗口占比 `≤25%`。 | `lint-event-density` 加 `--file` 指定本次 MP4。薄弱窗看主体是否真的推进，以及停顿是否承担角色。 |
| C7 动静变化 | 成片帧间差的 CV `≥0.30`，最长静止 `≤3.5s`。 | `lint-anti-ppt` 或 `check`。同任务有多份 MP4 时，用 §7 的文件级命令核对当前版本。CV 与低活动窗口各自记录。 |
| 真静停顿 | `anim rhythm --motion` 单独量死静占比 `≥25%`、最长静段 `≥1s`。 | 仅用于明确要求真静的段落或风格评审。需要微动的 `hold` 按角色评审，量具读数仍可记录。 |

`anim rhythm --strict` 负责 R1–R5 及表格式，双轨 `check --strict` 的判据还包含实际任务的结构、运动和跳过项。声音密度、显著性和人工评分先用于定位问题，验收按当前工具各自的退出码和评审证据记录。

## 6. 第二版待采读数

- **动作复杂度**按一个块内观众必须追踪的独立变化或因果链条计数，记动作和对应时刻。一个圆环由多层着色组成仍可只算一次扩散，多个同时需要分辨的方向或因果变化分别计。
- **重复度**先列出整片可辨认的动作事件。每次出现与前面同一主体、方向和结果的动作时计一次重复，以事件总数为分母，并注明用途。单块中同一动作用于连续推进时按一次事件计。两项先用样片校准，未采集时留空。

### 发布后验证完播

用有观众数据的同平台版本验证。先写明有效起播和到达片尾的口径，再记录 `3s` 留存、各峰谷前后流失及完播率。能区分播放会话时，完播率取 `到达片尾的有效播放会话 ÷ 有效起播会话`，同一会话只计一次。只提供分段观看比率的平台，按平台口径单列尾部观看比率。YouTube 的分段观看比率包含重看。 [YouTube Analytics 指标](https://developers.google.com/youtube/analytics/metrics#audience-retention-metrics)

做开场或节奏改版时，优先在相同内容主题、片长和流量来源下分流 A/B。记录两组样本量、完播率差及置信区间，并用留存曲线回看具体掉点。区间跨 `0` 时保留待验证结论。注意力节奏分用于发布前排查，完播结论来自实际观看数据。 [YouTube 留存曲线说明](https://support.google.com/youtube/answer/9314415)

## 8. 两支样片验算

下表以旧版 `out/beat/rhythm-motion-preview.mp4` 为 `beat` 基线。`demo` 使用 `out/demo/rhythm-eval-preview.mp4`，编码时长 `16.667s`，时间线 `16.65s`，相差不足一帧。

| 评审项 | `beat` 32 秒 | `demo` 16.65 秒 |
|---|---|---|
| 节奏表 | 7 块，覆盖全片，R1–R5 通过。 | 4 块，覆盖全片，R1–R5 通过。 |
| C4 / C5 | CoV `0.29`，完整呼吸窗 `1/1`。强事件 `3/4` 窗，末窗命中严格档问题。 | CoV `0.39`，完整呼吸窗不适用。强事件 `2/2` 窗。 |
| 成片运动 | 最长静止 `0s`，低活动窗口 `4/15`，约 `26.7%`，超线。C7 的运动 CV 为 `0.56`。 | 最长静止 `1s`，低活动窗口 `2/8`，恰为 `25%`。C7 的运动 CV 为 `2.19`。 |
| 注意力 | `133` 帧可比对主体框。首次释放平均主体内显著性 `65%`，热点落框 `14/26`。 | `69` 帧有像素显著性信号，均无有效主体框。集中度和轨迹可看，主体内占比及热点落框未评。 |
| 声音与拍网格 | 两次切点在 `10.7s`、`25.1s` 的 `release`，比最近拍分别晚 `237ms`、`139ms`，按参考读数记录。音轨为单层音乐，`sound_density` 声明仍需按 §4 复核。 | 无音轨，声音密度 `0`，拍网格不适用。 |
