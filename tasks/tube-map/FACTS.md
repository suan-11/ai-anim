# 地铁图｜事实依据

2026-11-22 核对维基百科 Tube map / Harry Beck 条目。片中口播为中文转述。

| 镜头 | 事实与允许表述 | 依据 |
|---|---|---|
| `close` | 第一张示意性地铁图由 **Harry Beck** 于 **1931 年**设计，**1933 年 1 月**以口袋版首发，立即流行。Beck 是伦敦地铁信号部门的工程制图员，主要画电气系统示意图。 | [Harry Beck](https://en.wikipedia.org/wiki/Harry_Beck) · [Tube map](https://en.wikipedia.org/wiki/Tube_map) |
| `mechanism` | Beck 的设计只用**直线与 45° 角**，每条线路配一个颜色。 | [Harry Beck](https://en.wikipedia.org/wiki/Harry_Beck) |
| `mechanism`/`compare` | 地铁图是**示意图（schematic / topological map）**：显示站点的**相对位置、连接关系、换乘与票价区**，而非地理位置与真实距离。 | [Tube map](https://en.wikipedia.org/wiki/Tube_map) |
| `compare` | 拓扑变形会**拉开市中心密集站点、压缩郊区稀疏站点**，使站距在图上趋于均匀。这是示意设计的常见结果（具体倍率因城市而异，片中为示意）。 | [Tube map](https://en.wikipedia.org/wiki/Tube_map) · 拓扑图通识 |
| `close` | 2006 年地铁图被评为英国十大设计图标之一。其设计概念被全球交通网络乃至概念示意图广泛采用。 | [Tube map](https://en.wikipedia.org/wiki/Tube_map) |

## 画面示意口径

| 画面 | 制作口径 |
|---|---|
| 地理坐标线网、拓扑网格、站点变形 | 抽象示意线网（非真实伦敦地铁图），站点身份与连接关系为编导安排，用于说明拓扑变形原理。 |
| 市中心/郊区站距对比、距离条 | 示意几何，倍率非实测；「站数相同」为拓扑保序的正确表述。 |
| 电路图意象、1933 年份 | 电路图呼应 Beck 制图员背景的史实；年份有出处。 |

## 刻意不写
- 不搬真实伦敦地铁图图形（版权），用抽象线网。
- 不给具体城市的具体站距倍率（无统一实测，避免编造数字）。
- 不声称拓扑图「精确」——它刻意牺牲地理精度换取可读性。
