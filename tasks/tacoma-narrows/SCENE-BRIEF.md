# 《一座钢桥，为什么会像布一样扭起来？》

任务 `tacoma-narrows`。35 秒，1920 × 1080，24 fps，中文旁白和引擎字幕。受众是没有结构工程背景的短片观众。

观众先亲眼看到**脚下的路往两边翻**，再从剖面看懂桥面与气流怎么互相影响，最后回到原机位看桥面断开。片尾把同一个截面交给风洞模型，回答工程师怎么在造桥前检查这种运动。

## 旁白和声音

录音按下表的起止窗交付。口播用自然语速和普通话，字幕交引擎。画面标注沿用分镜里的日期、名称和示意说明。

| 旁白窗口 | 口播 |
|---|---|
| 00.75–02.90 | 你脚下的桥面，正在往两边扭。 |
| 03.25–05.75 | 这天，横风吹过海峡上的吊桥。 |
| 06.00–08.85 | 桥面先上下起伏，接着左右扭转。 |

| 25.85–27.90 | 最后，桥的中跨坠入海峡。 |

用单层低音铺底和风声建立海峡环境，开头先让画面和钢索低响成立。剖面只在助推相位给很轻的音色变化。18 秒撤去大部分铺底，21 秒后恢复一点低频，25.50 秒用一声断裂，26.75 秒用压低的入水声。风洞段切为稳定气流和低声机械底噪，留出最后一句的空间。镜头切点不按 BPM，音效围绕物体动作摆放。

## 制作交接

- **模型分层。** 建一套桥塔、主缆、吊索、护栏和中轴线；首镜、全景和坍塌复用。沿跨距对桥面做局部横滚，护栏和吊索下端跟随对应桥面点。高低互换靠桥面网格变形，地平线与塔柱留在世界坐标。剖面和风洞模型复用桥面截面。
- **标注分工。** 现场镜用深蓝、冷白和低对比水纹。青色只标当前解释对象。03.25 秒给日期与桥名，`context` 与 `collapse` 镜显示「事故重建」，`mechanism` 显示「气流与扭转示意」，`close` 显示「风洞模型示意」。标注避开车道中线、截面边缘和字幕区。
- **首轮出样。** 先做 `hook`、`mechanism`、`close` 三个关键段，出全片时刻 **00.75、15.50、32.50** 的风格帧，并导出 **00.00–03.00** 静音动样用于审开场。制作侧可以从 `brief.mjs` 读取段起点、时长和段内峰值。
- **节奏检查。** 前 3 秒检查首帧主体和第一次换边。第一轮升幅落在 **14–18** 秒，**18–21** 秒回落。第二轮高点为 **25.50** 秒，**28** 秒进入风洞后回落。出样后用 [加权方差和峰谷标准](../../docs/RHYTHM-EVALUATION.md) 复查窗口，并为桥面或截面声明 `focus`。

## 验收点

1. 静音看 **00.00 / 00.75 / 01.75** 三张。无需读字就能指出哪一边先抬、哪一边后抬。桥塔和水线在三张中保持方向一致。
2. 静音看 **11.50 / 13.50 / 15.50** 三张。同侧三次极位清晰递增，来流方向和入画节奏保持一致。完整播放时能看清气流随桥板改变路径，并在下一摆前给出助推。
3. 对读 **25.50 / 26.75 / 28.00 / 32.50** 四张。断口、入水、支架、指针依次可辨，最后一镜一看就是缩尺试验。画面与声音都按两次峰谷走完，片尾给旁白和试验画面留足时间。
